If you want to use this project for daily usage monitoring, you might want to do some modifications to the project to improve its performance.

 1. Activate the time trigger on the [Build](scenario:BUILDFLOW) scenario.
 2. Change all the database connections to an SQL one (except for the input dataset).
 3. Change the execution engine to an SQL engine for all compatible recipes.
 4. Consider [partitioning](https://doc.dataiku.com/dss/latest/partitions/index.html) your dataset per day to make sure only the last slice of data is computed each day.
