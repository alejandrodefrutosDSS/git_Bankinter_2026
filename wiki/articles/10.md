This flow zone gathers all the analysis we make on the minute-by-minute logs.

The Local processes and Kubernetes processes are [stacked](recipe:compute_logs_capacity_planning_stacked) into one dataset and then we [compute](recipe:compute_logs_local_process_prepared_windows) the sum of CPU_current & Memory_MB over each minute to analyze the peak usage minute by minute.

Then, we compute 4 datasets that are going to be used in the final dashboard : 
1. [Logs by day & hours](dataset:logs_local_process_by_hours) : aggregates the resource usage per day & hours in order to display the usage heatmap in the dashboard
2. [Logs by minute](dataset:logs_local_process_by_minutes) : minute by minute total resource consumption
3. [Logs Top Memory usage](dataset:logs_local_process_memory_rank) : only keeps the minutes with the most memory usage
4. [Logs Top CPU usage](dataset:logs_local_process_CPU_ranked) : only keeps the minutes with the most CPU usage
