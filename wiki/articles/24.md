# Overview
## Solution goal
The  **GenAI Monitoring**  solution provides:
- a comprehensive overview of resource utilization and associated costs incurred by the usage of Large Language Models (LLM). 
- basic LLM usage charts (# requests, # tokens, latency)


It is designed to give project managers, IT and finance teams insights and control of cost allocation, efficiency, and optimization opportunities.
It prepares LLM usage related audit logs, generated by the Dataiku DSS platform, to be consumed via two dashboards.

## Solution value
### Cost Reduction (Finops) / Green AI
This project analyzes the use of LLM providers over time in order to monitor costs, whether financial or environmental.
It contains a monitoring dashboard [GenAI cost monitoring](dashboard:3NZ9w2C) aggregating expenses by project, user, usage type and LLM provider. If configured as such, it is updated daily via a scenario.
