# Overview
## Solution goal
The  **LLM Cost Guard**  solution provides:
- a comprehensive overview of resource utilization and associated costs incurred by the usage of Large Language Models (LLM). 
- budgeting per project capabilities and associated alerts.

It is designed to give project managers, IT and finance teams insights and control of cost allocation, efficiency, and optimization opportunities.
It prepares LLM usage related audit logs, generated by the Dataiku DSS platform, to be consumed via two dashboards.

## Solution value
### Cost Reduction (Finops) / Green AI
This project analyzes the use of LLM providers over time in order to monitor costs, whether financial or environmental.
It contains a monitoring dashboard [LLM cost monitoring](dashboard:3NZ9w2C) aggregating expenses by project, user, usage type and LLM provider. If configured as such, it is updated daily via a scenario.

### LLM mesh cache efficiency tracking
[LLM mesh cache](https://knowledge.dataiku.com/latest/ml-analytics/gen-ai/faq-cost-reduction-via-cache.html) is a feature provided by Dataiku to help you reduce costs. The  [LLM cost monitoring](dashboard:3NZ9w2C) dashboard gives you an overview of requests using the cache, along with an estimated saved cost.

### Budgeting
With its per project budgeting and continuous processing of audit logs, you are alerted whenever a project overrun its allocated budget.
