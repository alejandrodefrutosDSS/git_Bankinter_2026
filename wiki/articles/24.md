# Overview
The  **Cost Monitoring**  solution gives instance admin the ability to identify trends and spikes, and to analyze root causes by drilling down into data using multiple dimensions.

It prepares LLM Mesh related audit logs, generated by the Dataiku DSS platform from all the GenAI traffic going through LLM Mesh Connections, to feed dashboards periodically updated (daily, if configured as such.)
