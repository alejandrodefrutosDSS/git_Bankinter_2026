# Overview
The  **GenAI Monitoring**  solution provides:
- Comprehensive overview of resource usage and associated costs incurred by the usage of Large Language Models (LLM). 
- LLM usage charts (# requests, # tokens, latency)


It is designed to give instance admin insights and the ability to track usage and cost indicators, and to drill-down using multiple dimensions.
It prepares LLM usage related audit logs, generated by the Dataiku DSS platform, to be consumed via two dashboards.

### Cost Reduction (Finops) / Green AI
It contains a monitoring dashboard [GenAI cost monitoring](dashboard:3NZ9w2C) aggregating expenses by project, user, usage type and LLM provider. 
If configured as such, it is updated daily via a scenario.
