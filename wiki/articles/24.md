# Overview
## Solution goal
The  **LLM Cost Guard**  solution provides a comprehensive overview of resource utilization and associated costs incurred by the usage of Large Language Models (LLM). It is designed to give project managers and finance teams insights into cost allocation, efficiency, and optimization opportunities.
It prepares LLM usage related audit logs, generated by the Dataiku DSS platform, to be consumed via a dashboard.

## Solution value
### Cost Reduction (Finops) / Green AI
This project analyzes the use of LLM providers over time in order to monitor costs, whether financial or environmental.
It contains a monitoring dashboard  [LLM Usage](dashboard:tJacKJV) aggregating expenses by project, user, usage type and LLM provider. If configured as such, it is updated daily via a scenario.
