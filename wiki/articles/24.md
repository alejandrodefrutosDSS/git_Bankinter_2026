# Overview
## Solution goal
This solution helps you monitor LLM usage costs and stay on top of your expenses.
It contains a monitoring dashboard  [LLM Usage](dashboard:tJacKJV) aggregating expenses by projects and users. If configured as such, it is updated daily via a scenario.
