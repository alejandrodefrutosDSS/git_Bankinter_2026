# Overview
## Solution goal
This solution prepares LLM usage related audit logs to be consumed via a dashboard.

## Solution value
### Cost Reduction (Finops) / Green AI
This project analyzes the use of LLM providers over time in order to monitor costs, whether financial or environmental.
It contains a monitoring dashboard  [LLM Usage](dashboard:tJacKJV) aggregating expenses by project, user, usage type and LLM provider. If configured as such, it is updated daily via a scenario.
