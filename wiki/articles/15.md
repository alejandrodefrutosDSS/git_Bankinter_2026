This section details all the requirements needed to use this solution.

# Instance Requirements
This solution is compatible with **Dataiku DSS V13.0.1+**. Make sure your cloud instance has supported version, otherwise the solution is not guaranteed to work properly.

---
# Audit logs partitioning requirement
If you wish to activate continuous processing of audit logs, we **strongly suggest** to partition your audits logs per day or less and configuration partitioning in this project setup. This is to protect you from wasteful processing resource usage and it allows you to configure a faster refresh frequency and therefore a more up to date monitoring experience.

---

# Cloud Data Sources requirements
This solution requires the [**Audit Logs**](https://doc.dataiku.com/dss/latest/operations/audit-trail/dataikucloud.html#access-instances-audit-logs) extension to be installed. It will automatically add a new connection **dku-audit-log** to your connection pool. This connection can then be used to configure your application instance.

# Event Server Data Sources requirements
[Event Server](https://doc.dataiku.com/dss/latest/operations/audit-trail/eventserver.html) needs to be configured to dump logs in a location accessible via a connection configured in your Dataiku instance. It can be either an S3 or a file system connection.
