This section details all the requirements needed to use this solution.

# Instance Requirements
This solution is compatible with **Dataiku DSS V13.0.1+**. Make sure your cloud instance has supported version, otherwise the solution is not guaranteed to work properly.

---

# Data Sources requirements
This solution requires the [**Audit Logs**](https://doc.dataiku.com/dss/latest/operations/audit-trail/dataikucloud.html#access-instances-audit-logs) extension to be installed. It will automatically add a new connection **dku-audit-log** to your connection pool. This connection can be used to configure your application instance.
