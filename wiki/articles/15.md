This section details all the requirements needed to use this solution.

# Instance Requirements
This solution is compatible with **Dataiku DSS V12.4+**. Previous version compatibility is not guaranteed.
It also requires that the platform is installed on a Linux machine (incompatible with MAC or Windows versions).

---

# Data Sources requirements
This solution requires that one of the connections from the platform has  **access to the audit logs** . You will find more details in this [section.](article:9)
