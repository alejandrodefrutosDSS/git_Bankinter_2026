1. Import this project in your desired instance.
2. In the home page of the project, click on  **PROJECT SETUP**.
3. Choose the logs origin.
- For Cloud instances, select *Cloud logs*.
- If you host Dataiku yourself with [Event Server configured](https://doc.dataiku.com/dss/latest/operations/audit-trail/eventserver.html), select *Event Server logs*.
- If you want to test the solution capabilities with dummy data, select *Demo logs*.
3. Choose the connection where logs are available.
- For Cloud instances, select **dku-audit-logs**.
- For Event Server, select the connection you configured where Event Server logs are dumped.
- To use the anonymized demo logs included in this solution, leave the default connection **dataiku-managed-storage** as-is and go to step 6.
4. Click on the  **RECONFIGURE**  button to update the flow according to your selections.
5. Configure the path where the logs are.
- For Cloud instances, click on [compute_resource_usage_logs](dataset:compute_resource_usage_logs) dataset  to set */audit-logs/* as log path. 
- For Event Server, click on you can specify either the root path or the year or the month depending on your needs.
