To use this solution, you  _ **should not use the project itself** _   but the [Dataiku Application](https://doc.dataiku.com/dss/latest/applications/index.html) that comes with it. This application should be available on the  **home page of Dataiku under the Applications section**.

It will help you connect your data regardless of the connection type and configure the whole flow according to your settings seamlessly. 

  1. Create a new Dataiku application by clicking the  **CREATE APP INSTANCE**  button. This will create a new instance of the parent project that you can configure with your specific needs.
  
![DKU_app.png](SnX6PPdFYsHS)

1. Chose the connection that has access to the locations of the logs
2. Click on the "Reconfigure" button to update the flow connections to match the selected one
3. Click on the compute_resource_usage_logs dataset  to set the log path. Click on "Save" and go back to the Dataiku Application
4. You can select any of the options available :
 - "Partition the flow" : if you have event server logs activate this option to improve the performances of the build and enable incremental builds rather than recomputing entire history.
  - "Activate automatic night build" :  to enable automatic overnight flow build with latest data.
5. Click on the "Build" button. It can take several minutes, depending on the number of logs available
6. Open the  **Resource Consumption Report dashboard** or the  **LLM Usage dashboard** (applicable only if LLM Mesh is installed and used)
