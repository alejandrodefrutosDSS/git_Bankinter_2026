
The [Resource Consumption Report](dashboard:XbtxCLG) dashboard helps you analyze which project/user is consuming resources, and on which infrastructure. 
There are 4 tabs in this Dashboard.

## General Analysis : 

![Capture d’écran 2022-09-13 à 13.51.47.png](DyaFNSQfrJIw)

This helps you have a general overview of your consumption with:
- Distribution of resource consumption over days/hours: try to schedule jobs when the platform is under-used
- Distribution of resource consumption over each execution infrastructure: make sure user leverage SQL engine as much as possible, if available
- Most frequent job: check if there are any scenarios that keep triggering while they should not

## Instant Usage Monitoring : 

![Capture d’écran 2022-10-04 à 11.31.50.png](ZYdZmuRpdvsd)

Use this dashboard to help your capacity planning. You can investigate which project, user or recipe generated a CPU & memory peak. For each resource (memory & CPU) : 
- on the left, there is a chart showing the overall usage of the platform(s)
- on the right is a chart that displays the minutes with the highest resource usage. You can click on the chart to display a detailed view.
You can filter on the left on a date, execution location, project key, and user id

## Cumulative Usage Monitoring : 

![Capture d’écran 2022-10-04 à 11.31.57.png](Yk3thyy0Tqvw)

Use this dashboard to analyze which jobs consume the most resource over time, spot projects that should be optimized, and diminish your CO2 impact or financial cost.
You will find for each project its cumulative memory & CPU usage.

## SQL Details : 

![Capture d’écran 2022-10-04 à 11.32.02.png](zshn7B85Gz3u)

Use this dashboard to analyze the SQL execution time from all your projects. It displays the daily SQL execution time per project and the distribution of the execution over the available SQL connections.
