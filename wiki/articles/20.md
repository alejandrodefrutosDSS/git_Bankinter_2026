# Version 2.1.0 - 2024-11
 **Features** 
- Audit logs from log4j target are supported.
- Switch between DSS and SPARK engine for visual recipes.

**Fixes** 
- Fix issue when input dataset is a cloud storage and managed datasets are filesystem.
- "Projects over budget" and "Projects under budget" charts do not display an error when they are empty.
- Remove "Cumulative cost ($)" insight [LLM cost monitoring](dashboard:3NZ9w2C) as there is no more value to it.
- Add more decimals to "Average Estimated Cost per Request" in [LLM cost monitoring](dashboard:3NZ9w2C) metric so low values are not seen as 0.00.

**MISC** 
- Remove demo logs and its dependencies on S3 connection.

# Version 2.0.0 - 2024-09
