# Version 1.0.0 - 2024-07  
Initial release of the  [GenAI Monitoring](dashboard:3NZ9w2C)  solution, delivering comprehensive cost monitoring and management capabilities for LLM (Large Language Model) usage, along with advanced data processing.

**Features**  

- Dashboards
  -  **GenAI Cost monitoring**  :dollar:  
     - Total estimated cost ($)
     - Number of requests made to LLM providers
     - Requests answered by LLM Mesh cache
     - Total Estimated Cost ($) Over Time by Project
     - Total Estimated Cost ($) by Project
     - Total Estimated Cost ($) by User
     - Provider Estimated Cost ($) Distribution
     - Context Estimated Cost ($) Distribution
     - Usage type Estimated Cost ($) Distribution
  
  -  **GenAI Usage monitoring**  :bar_chart:  
     - Number of requests made
     - Average number of tokens by partition (broken down by prompt and output tokens)
     - Latency by partition (computation time in milliseconds)


- Audit Logs Support
  - GenAI Monitoring Guard supports Server log format.  
  - Continuous processing of audit logs (we strongly suggest enabling partitioning for this).  
  - Audit logs from log4j target are supported.  
  
- Partitioning
  - Partitioning support for efficient data handling.  
  
- Engine Flexibility
  - Switch between DSS and SPARK engine for visual recipes.
