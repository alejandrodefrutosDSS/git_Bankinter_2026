# Version 2.1.0 - 2024-11
 **Features** 
- Audit logs from log4j target are supported.

**Fixes** 
- Fix issue when input dataset is a cloud storage and managed datasets are filesystem
- Fix "Cumulative cost ($)" insight behaving unexpectedly in the dashboard due to a filter being applied to it.
- Add more decimals to "Average Estimated Cost per Request" metric so low values are not seen as 0.00.

**MISC** 
- Remove demo logs and its dependencies on S3 connection.
