The  **GenAI usage monitoring dashboard tab**  on the Dataiku platform provides a basic  **overview of usage of Large Language Models**  (LLM).

Those visualization aids in identifying trends, peak usage times, and potential spikes.

### Number of Requests
 **Time-Series Analysis:**  Track the evolution of LLM requests over time.
### Prompt Tokens
 **Boxplot Analysis:**  Track the evolution of prompt token usage over time.
### Completion Tokens
 **Boxplot Analysis:** Track the evolution of completion token usage over time.
 ### Latency
 **Boxplot Analysis:**  Track the evolution of LLM token latency over time.
