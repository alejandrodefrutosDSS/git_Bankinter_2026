Depending on the context and configuration of Dataiku, logs can be in different storages and formats. 
The supported logs format are:
- [Log4j target logs](https://doc.dataiku.com/dss/latest/operations/audit-trail/centralization-and-dispatch.html#log4j-target)
- Cloud instance logs
- [Event Server logs](https://doc.dataiku.com/dss/latest/operations/audit-trail/eventserver.html)

These different formats are handled in different sub-flows.

## log4j logs ingestion zone
![log4j_logs_ingestion.png](3HKbTk72e85X)
This zone ingests [log4j logs](https://doc.dataiku.com/dss/latest/operations/audit-trail/centralization-and-dispatch.html#log4j-target).

## Cloud logs ingestion zone
![cloud_logs_ingestion.png](KiacwX2O8JQM)

## Event Server logs ingestion zone
![eventserver_logs_ingestion.png](Q9DLh5ZGHTmG)

## LLM cost monitoring dashboard preparation zone
![to_dashboard.png](gvXyucMvuaC6)
This zone prepares the logs to be processed by the  [LLM cost monitoring](dashboard:3NZ9w2C) dashboard.

## Budget related features zone
![budget.png](9LohGBgueZVl)
This zone aggregates the consumed USD per project and compare it to the budgets configured. It does then some data preparation for dashboard visualization. It also contains [over_budget_notifications](dataset:over_budget_notifications) dataset that keep track of notifications to send.
