The GenAI cost monitoring page provides an overview of estimated costs generated by the usage of Large Language Models (LLM).

This page displays several charts tracking costs. It aims at identifying trends and dimensions influencing cost spikes, with the ability to drill-down and identify root causes via interactive filters.

### Cost Trends And Spikes Charts
Track the evolution of costs and LLM requests over time, broken down by individual projects, users, context, and more. These charts help to identify trends, peak usage times, and potential cost spikes.
 
- By Project: View how costs are allocated among different projects.
- By User: Identify which users are incurring the most costs.
- By Provider: Compare costs across different LLM providers.
- By Context: Analyze costs based on the environment in which operations occurred, helping you to pinpoint where resources are being consumed within DSS
- By Usage Type: Distinguish between costs associated with EMBEDDING (text vectorization) and COMPLETION (text generation) operations.

### Caching Efficiency Charts
 **Estimated Savings Visualization:**  A specialized chart presents the estimated cost savings attributed to LLM Mesh query caching. This metric is calculated by comparing cached query hits to the total potential cost, highlighting the financial impact of utilizing cache mechanisms.

### Filters And Dimensions
Use filters to drill-down and identify possible root causes across a combination of dimensions:

- Date
- Project
- User
- Provider: Identify providers, such as ```OPENAI``` or ```AZURE```.
- Connection: Identify LLM Mesh connections.
- LLM identifier: Identify the LLM.
- Context: Identify where the calls generating cost are from, among ```JOB_ACTIVITY```, ```JUPYTER_NOTEBOOK_KERNEL```, or ```WEBAPP_BACKEND```.
- Usage type
